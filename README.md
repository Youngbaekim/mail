# YB-Mail

학교 계정(ybkim@ssu.ac.kr)과 개인 계정(youngpeace@gmail.com)을 한 화면에서 쓰는 메일 앱 (PWA)
— Gmail API 직접 연결, Outlook 등 다른 앱의 로그인 속도 제한과 무관

## 실행 방법 (PowerShell)

```
cd C:\dev\yb-mail
npm install      # 처음 한 번만
npm run dev      # 개발 서버 → http://localhost:5173/mail/
```

- 점검용 가짜 메일함: 주소 끝에 `?demo` (로그인 없이 화면 점검, 새로고침하면 처음 상태)
- 배포: `main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포
- 새 버전 안내를 띄우려면 `public/sw.js`의 `VERSION`과 `package.json`의 `version`을 올린 뒤 배포

## 구성

| 항목 | 내용 |
|---|---|
| 로그인 | Google Identity Services 토큰 방식(서버 없음). 계정별 1시간 토큰, 이 기기에만 보관 |
| 권한 | `gmail.modify` (읽기·보내기·보관·라벨 변경, 영구 삭제 불가 → 삭제는 휴지통) |
| 배포 주소 | https://youngbaekim.github.io/mail/ (저장소 youngbaekim/mail) |
| Google Cloud | 프로젝트 `YB-Mail` (ID yb-mail-514606, youngpeace 계정 소유, 외부·테스트 상태), 테스트 사용자 = 두 계정, 웹 클라이언트 "YB-Mail Web" |
| 클라이언트 ID | `src/config.js`의 `CLIENT_ID` (비워 두면 첫 화면에서 입력, 기기별 저장) |

## 기능 (v0.1.0)

| 구분 | 내용 |
|---|---|
| 편지함 | 통합 받은편지함·별표·보낸편지함, 계정별 받은편지함·보낸편지함·별표·전체보관함·스팸·휴지통·라벨 |
| 목록 | 계정 색 띠·꼬리표, 날짜 묶음, 안읽음 표시·개수, Gmail 검색어, 안읽음만 보기, 아래로 내리면 더 불러오기, 90초마다 자동 확인 |
| 읽기 | 대화(스레드) 묶음 보기, HTML 본문 안전 표시(스크립트 차단), 본문 속 그림(cid), EUC-KR 메일, 첨부 열기·받기, 이전 내용 접기 |
| 쓰기 | 새 메일·답장·전체 답장·전달(원본 첨부 포함), 보내는 계정 선택, 참조·숨은참조, 받는 사람 자동 완성, 파일 첨부(끌어놓기·붙여넣기), 계정별 서명·보내는 이름 |
| 정리 | 보관·삭제(되돌리기)·읽음/안읽음·별표 |
| 단축키 | C 새 메일 · R 답장 · A 전체 답장 · F 전달 · E 보관 · Del 삭제 · U 안읽음 · S 별표 · J/K 이동 · / 검색 · Ctrl+Enter 보내기 |

## 알려진 제약

| 항목 | 내용 |
|---|---|
| 연결 유지 | 토큰이 1시간짜리라, 앱을 오래 닫아 두었다 열면 계정마다 '연결' 한 번씩 누름(창이 잠깐 떴다 닫힘). 사용 중에는 만료 직전 클릭 때 자동 갱신 |
| 테스트 상태 | Google 정책상 7일마다 동의 창이 다시 뜰 수 있음 |

| 임시보관 | 작성 중 메일의 임시보관함 저장은 아직 없음(다음 단계) |
