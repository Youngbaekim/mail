# YB-Mail

학교 계정(ybkim@ssu.ac.kr)과 개인 계정(youngpeace@gmail.com)을 한 화면에서 쓰는 메일 앱 (PWA)
— Gmail API 직접 연결, Outlook 등 다른 앱의 로그인 속도 제한과 무관

## 실행 방법 (PowerShell)

```
cd C:\dev\yb-mail
npm install      # 처음 한 번만
npm run dev      # 개발 서버 → http://localhost:5173/mail/
```

- 점검용 가짜 메일함: 주소 끝에 `?demo` (로그인 없이 화면 점검, 새로고침하면 처음 상태)
- 배포: `main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포
- 새 버전 안내를 띄우려면 `public/sw.js`의 `VERSION`과 `package.json`의 `version`을 올린 뒤 배포

## 구성

| 항목 | 내용 |
|---|---|
| 로그인 | Google Identity Services 토큰 방식(서버 없음). 계정별 1시간 토큰, 이 기기에만 보관 |
| 권한 | `gmail.modify` (읽기·보내기·보관·라벨 변경, 영구 삭제 불가 → 삭제는 휴지통) · 선택: `contacts.readonly`·`contacts.other.readonly`·`directory.readonly` (주소록 검색, People API 사용 설정 필요) |
| 배포 주소 | https://youngbaekim.github.io/mail/ (저장소 youngbaekim/mail) |
| Google Cloud | 프로젝트 `YB-Mail` (ID yb-mail-514606, youngpeace 계정 소유, 외부·테스트 상태), 테스트 사용자 = 두 계정, 웹 클라이언트 "YB-Mail Web" |
| 클라이언트 ID | `src/config.js`의 `CLIENT_ID` (비워 두면 첫 화면에서 입력, 기기별 저장) |

## 기능 (v0.7.0)

| 구분 | 내용 |
|---|---|
| 편지함 | 통합 받은편지함·별표·임시메일함·보낸편지함·스팸, 계정별 받은편지함·임시메일함·보낸편지함·스팸(나머지는 펼치기), 계정별 받은편지함·보낸편지함·별표·전체보관함·스팸·휴지통·라벨, 칸 너비 끌어서 조절(두 번 누르면 원래대로) |
| 기기 저장 | Gmail 서버가 원본, 이 기기(IndexedDB)에 사본. 계정별 받은편지함 최근 200통 본문 미리 받기(설정에서 0·100·200·500), 변경 여부는 historyId로 확인, 오프라인에서도 저장본 표시 |
| 목록 | Ctrl+클릭(하나씩)·Shift+클릭(범위)·**Shift/Ctrl+↑↓(누른 메일부터 범위를 넓혀 누적, Ctrl+클릭으로 모은 선택 유지)**·Ctrl+A(모두) 선택 → 일괄 삭제·보관·읽음·별표, 오른쪽 클릭 메뉴 |
| 읽기 | 첨부 목록을 본문 위에 표시, 첨부 누르면 [바로 열기: 다운로드 폴더 저장(+PDF·그림은 새 탭)] / [다운로드…: 위치 지정] / [모두 받기: 폴더 지정]. 서식 없는 메일은 쓰기 화면과 같은 맑은 고딕 14.5px |
| 쓰기 | 기본은 읽기 영역 전체, ⧉ 작은 창, ↗ 별도 창(메일을 보면서 작성). 캡처 그림 Ctrl+V → 커서 위치에 삽입, 그림 누르면 네 모서리로 크기 조절(보낼 때 본문 속 그림으로 첨부). 서명은 설정에서 계정별로 만들고 메일 맨 아래 자동 추가 |
| 쓰기 v0.3 | 쓰는 중 왼쪽 목록을 누르면 왼쪽 메일·오른쪽 쓰기로 나란히(경계 끌어서 조절), 서식 도구함(글꼴·크기·굵게·기울임·밑줄·글자 색·형광펜 — 다크 모드에서는 글자색을 밝은 톤으로 표시, 보내는 메일은 원래 색), 서명에도 같은 도구함 |
| 임시 저장 | [임시 저장] 단추, 저장 안 한 메일을 닫을 때 [임시 저장 / 저장 안 함 / 취소], 임시메일함에서 누르면 이어 쓰기, 보내면 임시본 자동 삭제 |
| 차단 | 오른쪽 클릭 → 보낸 사람 차단(Gmail 필터: 앞으로 오는 메일은 스팸함, 기존 메일도 옮기기 선택), ⚙ → 차단한 주소에서 해제 (권한 gmail.settings.basic) |
| v0.6 | 상단 오른쪽: 본문 확대·축소(− 막대 + 배율, Ctrl+/−/0, Ctrl+휠, 본문 좌우 핸들=줄바꿈 없이 메일 창 전체 확대·축소, 두 번 누르거나 상단 [창 N% ↺]로 원래 크기), 인쇄(A4 세로, Ctrl+P), 밝게/어둡게 전환(🌙/☀️). 목록 칸이 넓으면(720px~) 보낸 사람·제목·시각 열로 표시. 답장 시 서명은 원문 위(내 글 → 서명 → 원문). 원문: [원문 편집](일부 지우기·고치기) / [원문 빼기] / [원문 다시 넣기], 기본 포함. 대화 속 메일 카드마다 🗑(그 메일만 삭제, 휴지통에서는 ♻ 복원). 읽기 화면에서 예전 메일의 서명은 '이전 내용'에 접히지 않게 |
| v0.7.1 | 새 메일·답장·전달·이어 쓰기는 기본 별도 창(팝업, 크기·위치 기억). 쓰기 창을 창 닫기(X)로 닫으면 본 창이 임시메일함에 자동 저장. ⚙에서 '읽기 영역 안'으로 전환 가능, 휴대폰 화면은 항상 전체 화면 |
| 검색 (v0.8.0) | 혼합 검색: PC 저장본은 단어 일부·띄어쓰기 무시(para→parallels, 교육과정개편→교육과정 개편), 오래된 메일은 Gmail 서버 검색(단어 단위)으로 함께 표시. [조건 ▾] 펼침판: 포함·정확한 문구·제외·보낸 사람·받는 사람·찾을 곳(제목+본문/제목만)·기간(1주~1년·직접 지정)·상태(첨부·안읽음·별표)·범위(지금 편지함/전체, 스팸·휴지통 제외). 적용 조건은 칩으로 표시, 칩 ×로 개별 해제·[모두 지우기] |
| 발송 취소 | 보내기 후 설정한 시간(기본 30초, Gmail 웹 최대치와 같음) 동안 아래에 [메일 발송 취소: 제목] 표시 → 누르면 발송 취소·쓰기 창 복원 |
| 설치 | 프로그램으로 설치되지 않은 브라우저(Chrome·Edge)에서는 상단에 [설치하기] 단추 → 누르면 설치 창 (바탕화면·작업표시줄·시작 메뉴, 새 메일 바로가기) |
| 알림 | 받은편지함 새 메일만, 1분마다 확인, Windows 알림(오른쪽 아래)에 보낸 사람·계정·제목·본문 앞부분, 누르면 그 메일 열기. 앱(창)이 열려 있는 동안만 동작, ⚙에서 켜고 끔 |
| 받는 사람 자동 완성 (v0.7.0) | 이름·메일 일부를 치면 주고받은 기록 + 주소록(학교 디렉터리·내 연락처·기타 연락처)에서 사진·이름·메일로 추천(같은 이름은 메일로 구분, 자주 주고받은 사람 먼저). 주소록은 계정별로 한 번 [주소록에서도 찾기 — 켜기] 동의(읽기 전용, People API). 학교 정책으로 디렉터리가 막히면 연락처만 |
| 작업표시줄 숫자 (v0.6.5) | 창을 보지 않는 동안 두 계정에 새로 온 메일 수(대화 단위)를 남색 둥근 사각 + 흰 숫자로 표시(100 이상 99+), 창을 보면 0. 알림을 꺼도 1분마다 셈 |
| 단축키 | C 새 메일 · R 답장 · A 전체 답장 · F 전달 · E 보관 · Del 삭제 · U 읽음/안읽음 · S 별표 · J/K 이동 · / 검색 · Esc 선택 해제 · Ctrl+Enter 보내기 |

## 데스크톱 프로그램 (v0.5.0~)

Windows 설치판은 `C:\dev\yb-mail-desktop` (Electron). 같은 웹 화면을 쓰되 `window.ybDesktop`이 있으면 로그인 유지(갱신 토큰)·트레이 상주·첨부 바로 실행을 사용.
